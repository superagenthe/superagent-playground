# 本地数据格式

## 存储位置

应用使用浏览器 `localStorage`，键为 `todo.app.v1`。页面没有后端请求，任务标题、备注和清单内容不会离开当前浏览器。

## 顶层结构

```json
{
  "version": 1,
  "tasks": [],
  "lists": [
    {
      "id": "inbox",
      "name": "收集箱",
      "system": true,
      "createdAt": 1762700000000,
      "revision": 1
    }
  ]
}
```

`version` 是数据格式版本。当前应用只读写版本 `1`；读取到其他版本时展示“数据版本不兼容”，不会自动覆盖原始数据。

## 任务字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 创建时生成的唯一 ID，之后不变 |
| `title` | string | 单行标题，保存时去除首尾空白，1–200 个用户可见字符 |
| `description` | string | 多行纯文本备注，最多 5,000 个用户可见字符 |
| `status` | `"open"` / `"done"` | 未完成 / 已完成 |
| `priority` | `"high"` / `"medium"` / `"low"` | 高 / 中 / 低 |
| `dueDate` | `"YYYY-MM-DD"` / null | 本地日历日期，不含时间 |
| `listId` | string | 必须引用现有清单 |
| `createdAt` | number | 创建时间（毫秒时间戳），编辑不变 |
| `updatedAt` | number | 最近一次成功变更时间 |
| `completedAt` | number / null | 已完成时必填；重新打开时清空 |
| `revision` | number | 并发修改版本号，每次成功修改递增 |

## 清单字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 唯一 ID；系统清单固定为 `inbox` |
| `name` | string | 1–30 个用户可见字符；忽略大小写判重，不合并中间空格 |
| `system` | boolean | 收集箱为 `true`，不可重命名或删除；自定义清单为 `false` |
| `createdAt` | number | 创建时间；自定义清单按此从早到晚显示 |
| `revision` | number | 清单并发版本号 |

## 写入与并发

- 每次新增、编辑、完成、重新打开、删除或清单操作都会把完整数据一次性写入 `localStorage`；写入成功后 UI 才更新，失败时保留内存中的旧状态和表单输入。
- 编辑任务前会读取最新已保存数据并比较任务 `revision`。若记录已变化或删除，编辑器进入冲突状态，要求先重新载入，避免静默覆盖。
- 其他标签页保存后，当前页通过 `storage` 事件载入最新数据；正在编辑的表单会保留输入并提示冲突。
- 删除清单时，先用一次写入把该清单内全部任务移到 `inbox`，再删除清单；写入失败不会留下部分迁移结果。
- 应用启动时校验结构、版本、清单引用、任务/清单 ID 唯一性和完成时间一致性。损坏数据不会被自动清空；用户需先“重新读取”，重置则要连续两次确认。

## 重置与迁移

首版没有升级迁移逻辑：只支持 `version === 1`。重置会把数据替换为新的版本 1 数据，并重新初始化收集箱，不写入示例任务。
